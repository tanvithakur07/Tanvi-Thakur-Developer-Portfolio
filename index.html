MeetSphere

Full-stack video conferencing application

Overview

MeetSphere is a personal full-stack web application that explores the development of an online meeting platform. Users create meeting rooms, share meeting codes, communicate through audio and video, exchange messages and share their screens. A Spring Boot backend and MySQL database handle accounts and meeting data, while the browser handles live video and interactive features.

Features

  • Account management: registration, sign-in and password management.
  • Meeting rooms: create meetings and join with a unique meeting code.
  • Video and audio: real-time peer-to-peer communication with camera and microphone controls.
  • Screen sharing: present your screen to other participants.
  • Live chat: messages during meetings, with an unread count.
  • Participant management: participant list with camera and microphone status.
  • Meeting timer and email invitations with meeting details and a joining link.

Technology stack

  • Frontend: HTML5, CSS3, JavaScript
  • Backend: Java 17, Spring Boot 3.2, Spring Security, Maven
  • Database: MySQL 8.0, Spring Data JPA, Hibernate
  • Security: JWT authentication, BCrypt
  • Real-time: WebSocket for signalling and messaging, WebRTC for video and audio
  • Email: Spring Boot SMTP integration

Status

A personal project that runs locally and is not publicly deployed. Full details and screenshots are in the documentation PDF.

WorkTrack

Employee management and daily work tracking system

Overview

WorkTrack is a full-stack web application that brings three everyday workplace tasks into one place: an employee directory, daily work reporting, and leave requests from submission to decision. Administrator and Employee roles see different pages and have different permissions.

Features

  • Employee management: administrators add, edit and deactivate employees; new people receive an invitation email to set their own password.
  • Daily work tracking: employees log tasks with hours and status; administrators review team reports and see who has not reported.
  • Leave management: employees request leave and administrators approve or reject it; working days are counted automatically.
  • Dashboards and reports: summary cards and charts, with CSV and Excel export of work reports.
  • Email notifications: invitations, leave decisions and account changes, sent through a queue that shows each message’s status.
  • Access and history: role-based access, password change and an audit log.
  • Light and dark themes.

Technology stack

  • Frontend: HTML, CSS, JavaScript
  • Backend: Java 17, Spring Boot, Spring Security, Spring Data JPA, Maven
  • Database: MySQL with Flyway migrations
  • Security: server-session sign-in, CSRF protection, BCrypt password hashing, role checks
  • Email: SMTP, with retries and per-message status
  • Testing: JUnit

Status

A personal learning project that runs locally and is not publicly deployed. Full details and screenshots are in the documentation PDF.
